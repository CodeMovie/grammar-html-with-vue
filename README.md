# @codemovie/grammar-html-with-vue

Fork of https://code.haverbeke.berlin/lezer/html with extensions specific to
[Code.Movie](https://code.movie).

Includes a `vue` dialect to opt into text interpolation for Vue SFCs. The
`specialComponent` dialect opts into typing components (`<VueComponents>` as
well as `<web-components>`) differently from regular tags.
